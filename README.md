# MCH-Manuscript

Secondary data analysis of the National Survey of Children's Health (NSCH)
for a maternal and child health manuscript.

## Project structure

```
MCH-Manuscript.Rproj    Open this in RStudio to launch the project
R/                      Numbered analysis pipeline, run in order
  00_config.R            Packages, file paths, survey-design toggle
  01_import_data.R        Read raw file(s) from data/raw/
  02_clean_data.R         Missing-data recoding + eligibility criteria
  03_derive_variables.R   Exposure/outcome/covariate derivation + survey design object
  04_table1_descriptives.R  Table 1 (unweighted or survey-weighted)
  05_analysis_models.R    Primary/adjusted regression models
  06_figures.R             Manuscript figures
  99_run_all.R             Runs 00-06 in sequence
data/
  raw/                   Source data file(s) — git-ignored, see data/raw/README.md
  processed/             .rds files generated by the pipeline — git-ignored
output/
  tables/                Exported tables (.docx, .csv)
  figures/               Exported figures (.png)
docs/
  codebook_notes.md       Working notes mapping analytic variables to the source codebook
```

## Getting started

1. Open `MCH-Manuscript.Rproj` in RStudio.
2. Download the NSCH **Topical** data file(s) (SAS or Stata format) from
   https://www.census.gov/programs-surveys/nsch/data/datasets.html and place
   them in `data/raw/` (see `data/raw/README.md` for naming conventions;
   drop in more than one year's file to pool years automatically).
3. `R/00_config.R` is already configured for NSCH's complex survey design
   (`USE_SURVEY_DESIGN <- TRUE`, weight `fwc`, strata `fipsst` + `stratum`,
   no cluster/PSU variable) — adjust only if the design details differ for a
   specific NSCH year.
4. Fill in the `TODO`s in `02_clean_data.R` through `06_figures.R` as the
   study's exposure/outcome/covariates, eligibility criteria, and models are
   defined. Record variable definitions in `docs/codebook_notes.md` as you go.
5. Run the pipeline: `source("R/99_run_all.R")`, or step through each script
   individually.

## Package management

Scripts use [`pacman::p_load()`](00_config.R) to install/load dependencies
automatically on first run. If you'd rather pin exact package versions for
reproducibility, run `renv::init()` once the package set is finalized.
